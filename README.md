# ADB-PROJECT-

This project is a student portfolio and management system with a React frontend and an Express/MongoDB backend.

## Features
- Student registration and login
- Student portfolio/profile management
- Admin and faculty dashboards
- Analytics and reporting views

## Tech Stack
- Frontend: React, React Router, Axios
- Backend: Node.js, Express, MongoDB, Mongoose
- Deployment: Render/Vercel friendly structure

## Project Structure
- frontend/: React app
- backend/: Express API server
- render.yaml: deployment configuration

## Setup
1. Install dependencies:
   - npm install
   - cd frontend && npm install
   - cd backend && npm install
2. Start the app:
   - npm run dev

## Environment Variables
Create local .env files and do not commit them.
- Backend: backend/.env
- Frontend: frontend/.env

## Notes
- Do not commit secrets, API keys, or private database URLs.
- The repository is intended for source code and public-safe project files only.
